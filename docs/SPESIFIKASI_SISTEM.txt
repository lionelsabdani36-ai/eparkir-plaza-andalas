DOKUMEN SPESIFIKASI & RANCANGAN SISTEM E-PARKIR (PLAZA ANDALAS)BAB 1: PENDAHULUAN & SPESIFIKASI KEBUTUHAN1.1 Deskripsi SistemAplikasi E-Parkir Plaza Andalas adalah sistem manajemen parkir berbasis web yang dirancang untuk menangani proses masuk dan keluar kendaraan, pencetakan karcis otomatis berbasis kode unik (Token/QR Code), pengelolaan pelanggan berlangganan (Member), transaksi pembayaran tunai di pintu keluar, hingga pelaporan keuangan terpusat.1.2 Aktor dan Hak Akses (Role)Sistem memiliki 3 kategori pengguna dengan pembagian hak akses sebagai berikut:NoAktorSub-KategoriHak Akses & Fitur Utama1UserNon-Member- Mengakses Landing Page di pintu masuk.- Menekan tombol PRINT untuk mendapatkan karcis berisi nomor Token dan QR Code.- Menerima Invoice pembayaran setelah transaksi di pintu keluar.2UserMember- Melakukan Scan QR pada Kartu Member saat melewati pintu masuk.- Membayar tagihan langganan di setiap awal bulan.- Menerima Kartu Member dan Invoice pembayaran bulanan.3PetugasStaf Kasir / Pintu Keluar- Melakukan Login dan Forget Password.- Mengelola akun profil diri sendiri.- Melakukan pemindaian (Scan) QR / input Token karcis Non-Member.- Menginput transaksi pembayaran parkir (Kategori kendaraan, No. Plat, Uang Tunai) untuk Member dan Non-Member.- Mengelola data Member (CRUD), melihat detail riwayat pembayaran (Lunas/Belum Lunas), dan mencetak Kartu Member.- Melihat dan mencetak laporan transaksi Member dan Non-Member.4Super AdminAdministrator Tunggal (1 Akun)- Melakukan Login dan Forget Password.- Mengelola akun Petugas (CRUD: Tambah, Lihat, Edit, Hapus).- Melihat, mencari (Search), dan mencetak laporan pembayaran Member serta Non-Member dari seluruh petugas.BAB 2: REKOMENDASI ARSITEKTUR & TECH STACKUntuk memenuhi standar kompetensi pengembangan perangkat lunak berbasis Object-Oriented Programming (OOP) dan Structured Programming, berikut adalah spesifikasi teknologi yang direkomendasikan:2.1 Spesifikasi Platform & FrameworkBackend: PHP 8.2+ dengan Framework Laravel 10/11 (Arsitektur MVC, mendukung penuh konsep OOP, Middleware otorisasi, dan Unit Testing menggunakan PHPUnit).Frontend & Styling: Blade Templating Engine + Tailwind CSS (memudahkan pembuatan desain antarmuka modern dan glassmorphism sesuai mockup) + Alpine.js / Vanilla JavaScript (untuk interaksi real-time).Database Management System (DBMS): MySQL / MariaDB (Relasional, mendukung Foreign Key dan transaksi ACID).Web Server Lokal (Development): Laragon atau XAMPP (Apache/Nginx).2.2 Library Pendukung (Third-Party Packages)QR Code Generator: simplesoftwareio/simple-qrcode (membuat gambar QR Code untuk karcis Non-Member dan Kartu Member).QR Code Scanner: html5-qrcode (library JavaScript untuk membaca QR Code melalui webcam atau scanner di halaman Petugas).Cetak Dokumen/PDF: barryvdh/laravel-dompdf dan fitur window.print() CSS @media print untuk mencetak struk karcis, kartu member, invoice, dan tabel laporan.2.3 Konfigurasi EnvironmentDevelopment (APP_ENV=local, Rumus Perhitungan Transaksi pada Sistem:Durasi Parkir (Jam):
$$\text{Durasi} = \lceil \text{Waktu Keluar} - \text{Waktu Masuk} \rceil$$Total Tagihan Non-Member:
$$\text{Total Tagihan} = \text{Tarif Dasar Kategori} + ((\text{Durasi} - 1) \times \text{Tarif Per Jam})$$
(Catatan: Berdasarkan mockup karcis, tarif 1 jam pertama Rp 3.000 dan jam berikutnya berlaku kelipatan sesuai kebijakan pengelola).Perhitungan Uang Kembalian:
$$\text{Kembalian} = \text{Uang Tunai} - \text{Total Tagihan}$$
Syarat validasi pembayaran: $\text{Uang Tunai} \ge \text{Total Tagihan}$.3.3 Kode Mermaid Flowchart (Untuk Visualisasi Diagram)(Kode di bawah ini dapat disalin ke Mermaid Live Editor untuk diekspor menjadi gambar PNG/SVG):flowchart TD
